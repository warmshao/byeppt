## 特点

- **一句话生成 PPT**：输入一个想法，自动生成整份幻灯片，并可在应用内实时预览每一页的生成过程。
- **自带模型服务管理**：支持多家模型服务供应商，填入自己的 API Key 即可使用。
- **内置 vsurf 浏览器 Agent**：集成了 [vsurf](https://github.com/warmshao/vsurf)。vsurf 是基于 pi 构建的 browser-first RLM Agent，缓存命中率显著更高，即使较简单的模型也有不错效果；同时支持浏览器控制，可搜索最新新闻来制作 PPT。

## 使用

前往 [Releases](https://github.com/warmshao/byeppt/releases) 下载对应平台的安装包。

**macOS 用户注意**：目前安装包尚未签名。首次打开时，请在 **系统设置 → 隐私与安全性** 中点击 **仍要打开**，按提示完成安装。
